# 實驗 D 完成結果

使用真正的本機 **Clef-Flash 9B Q4_K_M 原生 System One**，沒有另用此次資料訓練，也沒有使用既有 TF-IDF 模型代替。共 210 筆固定測試，API 錯誤 0 筆。

| 指標 | 結果 |
|---|---:|
| 原始模型路由正確 | 192／210，91.43% |
| 最大路由機率 ≤ 0.6 而拒判 | 33／210，15.71% |
| 通過機率門檻 | 177／210，84.29% |
| 通過門檻案例正確率 | 169／177，95.48% |
| 門檻後最終路由正確 | 169／210，80.48% |
| 程式組裝 JSON 可解析／Pydantic 通過 | 100%／100% |
| 格式及最終路由同時正確 | 169／210，80.48% |
| 平均／P95 耗時 | 0.375／0.391 秒 |
| 210 筆推論累計耗時 | 78.65 秒 |

分類低分依使用者原有設定轉 clarification，沒有為了成績更改 0.6。正式測試正解沒有 clarification，所以每筆拒判都不計為路由命中；這是現有評估定義，不能解讀成拒判必然沒有實務價值。原始模型另有 3 筆直接預測 clarification 且超過門檻，因此最終 clarification 共 36 筆。

D 的格式是**程式組裝**，模型只提供 route 與 intent 選項機率。slots 由文字規則抽取，status、missing_slots、next_action 由規則決定；五個 slots 全部保留，未知為 null。此格式 100% 不代表模型自行生成 JSON 的能力；也沒有完整 slots 人工正解可供語意評分。

與 A 平均約 0.923 秒相比，本次 D 約快 2.46 倍，但模型、介面及輸出機制不同，不能將差異完全歸因於 System One 方法。最終路由正確率仍低於 B 的 91.90%。

獨立稽核核對 210 筆原始問題、正解、七路由選項、完整原生機率、嚴格 0.6 邊界、全部五個 slots、逐筆重算評分及模型服務關閉，見 audit.json。沒有依照測試成績調整問題或門檻。
